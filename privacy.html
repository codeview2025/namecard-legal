NameCard 개인정보처리방침

최종 개정일: 2026-09-01 버전: 1.4.5

CodeView2025(재능기부)(이하 "회사")는 「개인정보보호법」을 준수하며, 다음과 같이 회원의 개인정보를 보호합니다.

1. 수집하는 개인정보 항목

1-1. 회원 본인 정보

  • 필수: 이메일 주소, 닉네임, 프로필 사진 URL (Google 계정 연동 시)
  • 선택: 본인 명함 정보 (이름, 회사, 직책, 연락처 등)

1-2. 회원이 등록하는 제3자(거래처) 명함 정보

⚠️ 이 정보는 회원의 기기에만 저장되며, 회사 서버(클라우드)로 전송되지 않습니다.

현재 버전은 명함 정보의 클라우드 동기화 기능을 제공하지 않으므로, 아래 항목은 전부 회원의

기기 내부에만 보관됩니다. (추후 여러 기기 간 동기화 기능을 추가하는 경우, 시행 전 본 방침을

개정하고 회원에게 사전 고지합니다.)

  • 이름, 영문명, 회사, 부서, 직책
  • 휴대전화·회사전화, 이메일, 웹사이트, 주소
  • 메모, 명함 사진
  • 명함 출처 기록 (대면/행사/거래처 전달/OCR/가져오기 등)

1-3. 자동 수집 정보

  • 기기 식별자, OS·앱 버전
  • 광고 식별자(Advertising ID) — 광고 게재 목적 (Google AdMob)
  • 서비스 이용 로그 (오류·성능 분석)
  • IP 주소 (보안 사고 대응 목적, 최대 90일 보관)

  • 회원 탈퇴 즉시 모든 데이터 영구 삭제 (단, 아래 예외 적용)
  • 관계 법령에 따른 보존 기간
    • 통신비밀보호법: 접속 로그 3개월
    • 보안 사고 대응: IP 로그 90일
  • 본 서비스는 현재 결제·전자상거래 기능을 제공하지 않으며, 유료 서비스 도입 시 전자상거래법 등에 따른 보존 의무를 반영해 본 방침을 개정합니다.

4. 개인정보의 제3자 제공

회사는 회원의 동의 없이 개인정보를 제3자에게 제공하지 않습니다.

다만 다음의 경우에는 예외적으로 제공할 수 있습니다.

  1. 회원이 사전에 동의한 경우
  2. 법령에 특별한 규정이 있는 경우
  3. 법원의 영장·수사기관의 적법한 요청

6. 회원이 등록한 제3자(거래처) 명함 정보에 대한 특별 고지

⚠️ 중요: 회원이 거래처·지인의 명함을 등록할 경우, 해당 명함 정보 주체에 대한 개인정보보호법상 의무는 1차적으로 명함을 등록한 회원에게 있습니다.

본 서비스는 이 정보를 기기 저장(로컬 전용)으로만 처리합니다. 현재 버전은 클라우드 동기화

기능을 제공하지 않으므로, 회사는 이 정보를 서버에 수집·저장하지 않으며 회원의 기기에만 남습니다.

(추후 동기화 기능을 도입하는 경우 본 방침을 개정하고 사전 고지하며, 그 시점부터 회사도 정보주체

관점에서 개인정보처리자로서 안전조치 의무를 지고 아래 6-1/6-2 내용이 적용됩니다.)

6-1. 회원의 의무

  • 명함을 받을 때 명함 주체로부터 명시적 또는 묵시적 동의를 얻어야 합니다 (대면 교환·세미나 등은 묵시적 동의로 인정).
  • 명함 정보를 본인의 명함 관리 목적 외(마케팅, 제3자 양도, 자동 발송 등)로 사용해서는 안 됩니다.
  • 명함 주체가 정보 삭제를 요청할 경우 회원은 즉시 해당 명함을 삭제해야 합니다.

6-2. 회사의 조치

  • 명함 등록 시 출처(대면 교환·행사·전달받음 등)를 기록하여 추후 분쟁 시 입증 자료로 활용합니다.
  • "거래처 전달" 또는 "파일 가져오기" 출처로 등록되는 명함은 회원의 명시적 동의 확인을 거칩니다.
  • 명함 주체로부터 직접 삭제 요청(codeview2025@gmail.com)이 들어올 경우 회사는 회원에게 통지하고 해당 명함을 삭제할 수 있습니다.

7. 회원의 권리

회원은 언제든지 다음 권리를 행사할 수 있습니다.

  1. 열람권: 본인 정보 조회 (앱 내 "내 명함" 메뉴)
  2. 정정·삭제권: 본인 정보 수정·삭제
  3. 처리정지권: 동의 철회 가능
  4. 데이터 이동권: 개인정보 CSV/vCard 내보내기
  5. 탈퇴권: 앱 설정 > 회원 탈퇴 (즉시 영구 삭제)

권리 행사는 앱 내에서 직접 가능하며, 추가 문의는 codeview2025@gmail.com 로 보내주세요.

8. 안전성 확보 조치

  • 통신 구간: TLS 1.3 암호화
  • 저장 시: Firebase 기본 암호화 (AES-256)
  • 인증: 토큰 정기 회전, App Check (Play Integrity/App Attest)
  • 접근 권한: IAM 최소 권한 원칙, 2단계 인증
  • 로그 감사: 비정상 접근 탐지·자동 알람
  • 보안 사고 발생 시: 「개인정보보호법」제34조에 따라 72시간 내 회원 통지 및 관계 기관 신고

9. 개인정보 자동 수집 장치 (쿠키)

  • 본 서비스는 앱 형태로만 제공되며, 쿠키를 사용하지 않습니다.
  • 회사가 별도로 운영하는 안내용 웹페이지(본 방침 게시 등)는 정적 페이지로 쿠키를 사용하지 않습니다.

  • 법정대리인 동의 없이 수집된 아동 정보 발견 시 즉시 삭제합니다.
